# Web CV - Thiết kế hiện đại & tối giản

CV trực tuyến với thiết kế tập trung vào typography và tông màu tươi sáng.

## Tính năng

- **Typography-first**: Sử dụng DM Serif Display + DM Sans từ Google Fonts
- **Tông màu tươi sáng**: Teal (#2DD4BF), Amber (#F59E0B) trên nền cream (#FFFBF5)
- **Responsive**: Tối ưu cho mobile, tablet và desktop
- **Print-friendly**: Hỗ trợ in ấn

## Chạy thử

Mở file `index.html` trực tiếp trong trình duyệt hoặc dùng Live Server:

```bash
# Nếu có Python
python -m http.server 8000

# Nếu có Node.js (npx serve)
npx serve .
```

## Tùy chỉnh

Chỉnh sửa `index.html` để cập nhật thông tin cá nhân:
- Tên, chức danh, mô tả
- Kinh nghiệm làm việc
- Học vấn
- Kỹ năng
- Thông tin liên hệ

Màu sắc và typography có thể điều chỉnh trong `styles.css` (biến CSS ở đầu file).
